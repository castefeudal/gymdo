# r75.1 release and audit record

## Changes

- Exercise preview GIFs animate while a touch card is visible and for mouse hover or keyboard focus. They stop offscreen or when reduced motion is requested.
- The desktop “Ещё” menu reserves space for its existing icons, stays inside the viewport, and scrolls internally when the screen is short.
- Release version: `2026.10-r75.1-gif-and-nav-polish`.

## Verification

- `npm run quality`: syntax, generated production assets, all performance budgets, and 188/188 unit tests passed.
- Targeted Playwright coverage: GIF and menu tests passed across Chromium desktop, Chromium mobile, Firefox, and WebKit; the desktop menu test is intentionally skipped for the mobile navigation surface.
- Axe checks on 10 main routes passed without serious or critical violations at desktop and mobile Chromium, Firefox, and WebKit widths.
- The broad `production.spec.mjs` and `accessibility.spec.mjs` run reported 167 passed, 3 skipped, and 2 teardown timeouts while Playwright recorded traces. Both timed-out scenarios passed when rerun individually without trace recording.
- Performance budgets after the release build: initial JavaScript 446,327 B / 480,000 B; full runtime JavaScript 516,415 B / 520,000 B; CSS 273,481 B / 276,000 B.

Automated checks cover declared scenarios and are not a substitute for human usability testing or formal accessibility certification.
